Icon Badge

生成可用于 README、文档页面、门户系统和普通 HTML 的 SVG badge。配合 Nginx njs 后，可以通过 URL 参数直接返回 SVG。

部署和使用

动态部署时使用 nginx/badge.js 和 nginx/icon-badge.conf。访问根路径并携带 key、value、bg 参数即可直接返回 SVG。

示例：https://svg.example.com?key=Lang&value=Java17&bg=green。生成器页面建议挂到 /ui/。
